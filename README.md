# Sample Superstore Data Analysis

An end-to-end data analysis project based on the **Sample Superstore** dataset, using **Python, SQL, and Power BI** to explore sales performance, profitability, customers, products, and regional trends.

## 📌 Project Overview

The goal of this project is to analyze Superstore sales data and extract meaningful insights from different aspects of the business.

The project combines:

* **Python** for data cleaning, preprocessing, and exploratory data analysis
* **SQL Server** for querying and analyzing structured data
* **Power BI** for data visualization and interactive dashboard development

* **Power BI**

## 📊 Analysis

The project focuses on several key business questions, including:

* What are the overall sales and profit trends?
* Which products and categories generate the most sales?
* Which products and regions are the most and least profitable?
* Who are the most valuable customers?
* How do sales and profit vary across regions and states?
* What are the trends in sales and profitability over time?
